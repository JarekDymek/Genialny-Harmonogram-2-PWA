# Genialny Harmonogram 2 — PWA

[Otwórz aplikację i instalację](https://genialny-harmonogram-2-jarekdymek.onrender.com/instalacja)

Android: Chrome → menu → Zainstaluj aplikację / Dodaj do ekranu głównego.
iPad/iPhone: Safari → Udostępnij → Do ekranu początkowego.
Komputer: Chrome/Edge → opcja instalacji aplikacji.

Repozytorium zawiera wyłącznie wygenerowany interfejs. Aplikacja jest hostowana razem z API na oddzielnej domenie Render; pliki mają ścieżkę bazową `/` i nie są przeznaczone do bezpośredniego hostowania w podkatalogu GitHub Pages. Prywatne źródła i dane referencyjne nie są publikowane tutaj.

Przenoszenie danych między urządzeniami: eksport/import projektu JSON. Wersja 1 pozostaje oddzielna.
